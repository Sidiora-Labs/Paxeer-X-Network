# Kindle SDK

The frozen v1 DTOs, schemas and `release-manifest.json` remain reproducible. Versioned v2 DTOs come from `@kindle/sdk-v2`; `generate:operations` derives the typed operation catalog from the matching OpenAPI3.1 document and verifies its definitions against JSON Schema2020-12 and AsyncAPI. Never edit generated output. The phase2 evidence manifest records the v2 input, emitter and output digests. No compatibility window is inferred from a major number: the semantic checker requires an explicit reviewed window for breaking contract changes.

Construct `SdkClient` once with API, identity, media and allowlisted stream origins. Production requires HTTPS/WSS and rejects private service endpoints. Bearer tokens stay in Authorization. Cookie operations require the application origin and CSRF policy; login and refresh explicitly select cookies. The deployment front door must route each published media and identity operation to its actual service. Neither credentials nor server error details are copied into error messages.

`new Operations(client).call('IF_TRADES', {path: {poolAddress}, query: {limit: 100}}, {signal})` validates path/query/body and response using the admitted v2 contracts. Operation metadata selects the service, timeout and authentication. Only documented GET reads receive at most two retries. Mutations receive none. Idempotency headers require the operation’s published contract. Public reads share only simultaneous in-flight work; aborting one consumer cannot cancel another consumer’s request. Private reads never share that cache. Unknown endpoints expose `CapabilityUnavailableError`; published errors retain their stable code and request ID in `HttpError`.

`SnapshotStreamV2` synchronously installs a complete snapshot, including its watermarks, before releasing replay events after the acknowledged checkpoint. Store effects must commit synchronously. Failed effects do not advance client positions. Sequences and money remain decimal strings in JSON and BigInt internally; PAX18 and USDL6 retain separate brands. Display formatting requires explicit rounding and may carry the generated price provenance.

`ReconnectingStream` keeps authorized cursors in memory, obtains a new one-use ticket per attempt and applies full jitter from500ms to30seconds. Its attempt counter resets after30seconds live. Visibility restore validates the72hour cursor lifetime; expired history fetches a snapshot. Authentication failures stop retries. Circuit opening retains stale data; `retry()` resumes explicitly. Logout and permission changes clear cursor state.

Browser callers use `acquireCanonicalDataStream` and `useCanonicalDataStream` from the realtime module. One shared connection multiplexes an explicit union of at most20topics per authorization scope. Empty topics are rejected; the21st topic requires an explicit separate connection policy. Immutable fills are delivered individually. Replaceable state alone is coalesced per animation frame. Consumer errors remain isolated, and cleanup releases its own subscription. Existing `subscribe` is retained as `subscribeLegacyDelta` for the historical `/ws` transport.

`examples/pagination.mjs` and `examples/snapshot-resume.mjs` are emitted from the selected operations. Set `SDK_CONNECTED_CONFIG` to the coordinator’s real-service fixture configuration. The latter supports public subscriptions or authenticated fresh tickets and `SDK_RESUME=1` for durable reconnect. The fixture supplies public HTTPS/WSS origins, actual session credentials, topics and canonical pool identities. Examples fail on unavailable authority rather than returning empty success.

`test:phase2` consumes precompiled SDK output and runs the deterministic generation/compatibility checks, existing primitive assertions, actual-service journeys and React StrictMode lifecycle checks. It does not build. The coordinator fixture must supply digest-bound executable commands for snapshot/ack fill insertion, delayed requests, gateway restart, retained-history expiry/session revocation and100real fills. Missing fixture capabilities fail qualification. The existing isolated protocol tests are primitive coverage; they are not durable-service evidence.
