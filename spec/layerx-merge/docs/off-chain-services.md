# Off-chain services

Service contract version 1.0.1. This page lists every off-chain service that runs beside the Paxeer X Network after the LayerX kernel domain is folded into the chain: 36 services, 33 retained and 3 new (archive node, perps keeper, AI evaluator service). For each service it names the package path, the chain methods it calls, what it reads, how the chain authorises what it submits, and what it does when the chain or the sequencer is unavailable.

Conventions used in every table:

- Chain methods are written as exact ABI signatures (argument types only) with the precompile address; selectors are given where the frozen contract fixes them.
- `eth_sendRawTransaction` (rpc/send.go:76) is served by the sequencer, which executes the transaction in receipt order before it answers; `pax_sequencerReceipt(txHash)` is the new sequencer method that returns the signed receipt with the rung submitted, receipted or committed.
- Reads tagged "pending" go to the sequencer; other nodes answer -32000. Today every node maps the pending tag to latest (rpc/utils.go:66).
- Every sponsored write goes through the gas station `executeSponsored` path (ADR D14). Every service EVM sender key is loaded by one shared keystore-or-KMS loader selected by environment and the sender address is registered with the gas station.
- The sequencer receipt is signed with a separate ed25519 receipt key per host (ADR D15), pinned with a key id and height range in the `ReceiptKeys` list of the new `modules/sequencer` params. Verifiers check receipts against that list.
- "New" paths do not exist at the cited revision and are created by this feature.
