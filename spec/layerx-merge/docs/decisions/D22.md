# D22: Agent functions 0x0901-0x0904

Status: decided

## Context
The gateway routes orob, clearing, oracle and pofq to 0x0901-0x0904 (human/wallet/gateway/src/precompiles.ts:18-21). This repository has no ABI and no execution function for these four. Their original semantics exist in the earlier implementation's precompiles and Solidity interfaces.

## Options considered
| Option | Consequence |
|---|---|
| A: take the semantics from the earlier implementation and build each as a real precompile | Eight agent functions as in D20; four new specifications and vectors |
| B: drop the four from the port and keep 0x0905-0x0908 | D20 shrinks to four functions; routes deleted |

## Decision
Option A is decided: orob, clearing, oracle and pofq take their semantics from the earlier implementation, are re-specified in the agent contract and are implemented anew as real precompiles at 0x0901-0x0904. Nothing is copied. D20 stays at eight functions.

## Consequences
- New precompiles at 0x0901-0x0904 behind the existing gateway routes (human/wallet/gateway/src/precompiles.ts:18-21).
- Each function carries its own specification and vectors.

## Affects
- Addresses: 0x0901 orob, 0x0902 clearing, 0x0903 oracle, 0x0904 pofq
- Modules: layerxagent precompiles
