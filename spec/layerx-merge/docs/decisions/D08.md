# D8: Trading semantics where kernel and exchange differ

Status: decided

## Context
The kernel and the exchange module differ on order id, market creation, book capacity, the spot settlement request and the launchpad fee accumulator. The kernel caps each book at 256 entries and each dispatch at 8 fills (include/layerx/lx_perps.h:27, include/layerx/lx_perps.h:34, include/layerx/lx_spot.h:21-22), names a market administrator (include/layerx/lx_perps.h:162), and its spot activity set has no settlement request (src/modules/spot/lx_spot_dispatch.c:11-14). The exchange keeper records orders today (modules/layerxexchange/keeper/intents.go:105).

## Options considered
| Option | Consequence |
|---|---|
| A: kernel semantics (client-chosen order id, permissionless markets with a self-named administrator, cap 256 and 8 fills, spot settlement refused, global launchpad accumulator) | Parity with kernel goldens and the SDK; launchpad swaps serial under OCC |
| B: exchange semantics (chain-derived order id from chain, caller and nonce; authority-only market creation; raised caps; spot settlement removed; per-market accumulators) | No id collisions; SDK order API changes; per-market accumulators run in parallel |

## Decision
Decided item by item. Order id: chain-derived from chain, caller and nonce (B). Launchpad fee accumulator: per market (B). Market creation: permissionless with a self-named administrator (A). Book capacity 256 with 8 fills per dispatch (A). Spot settlement request: refused, as in the kernel (A).

## Consequences
- The layerxexchange Msg set carries permissionless market creation, the kernel caps and the refused spot settlement (src/modules/spot/lx_spot_dispatch.c:11-14).
- The SDK order API reads the chain-derived order id from the receipt; order-id goldens and SDK vectors are re-pinned (modules/layerxexchange/keeper/intents.go:105).
- The launchpad keeper keeps one fee accumulator per market, parallel under OCC; getConfig and fees vectors are re-pinned (precompiles/launchpad/launchpad.go:3).
- Parity targets: kernel goldens for caps, market creation and the spot refusal (include/layerx/lx_perps.h:27).

## Affects
- Addresses: 0x1015 layerxexchange, launchpad
- Modules: layerxexchange, launchpad, agent SDK
