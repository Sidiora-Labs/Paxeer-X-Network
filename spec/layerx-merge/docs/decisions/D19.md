# D19: Sequencer execution mode

Status: decided

## Context
The sequencer executes every transaction at receipt against a speculative branch of committed state. The kernel sequencer carries an allocator and an admission queue (include/layerx/lxp_sequencer.h:12, include/layerx/lxp_sequencer.h:25).

## Options considered
| Option | Consequence |
|---|---|
| A: strictly sequential | Simplest; throughput of one core |
| B: OCC micro-batches of about 1 ms in receipt order | Parallel throughput; about 1 ms added to receipt latency |

## Decision
Option B is decided: OCC micro-batches in receipt order. The strictly sequential executor lands first, in the first wave, and the switch to OCC micro-batches is made on a throughput and receipt-latency measurement of both.

## Consequences
- The strictly sequential executor lands first (include/layerx/lxp_sequencer.h:25).
- Throughput and receipt latency are measured, sequential against OCC micro-batch.
- The micro-batch size and switch thresholds are set from that measurement.

## Affects
- Addresses: none
- Modules: sequencer
