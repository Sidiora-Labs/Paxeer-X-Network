# D10: Paid search settlement and lxpay placement

Status: decided

## Context
Paid web search over 402LXP at USD 0.001 per request needs a settlement path and a home for lxpay. The draw sender class pays gas at the EVM minimum fee per gas, a governance parameter (modules/evm/types/params.go:81).

## Options considered
| Option | Consequence |
|---|---|
| A: per-request draw, at most 0.067 gwei for the draw sender class, through a new lxpay precompile at 0x101A | One receipt per request; x402 suite unchanged |
| B: voucher channel, about USD 8e-7 per request, released on the payer voucher | Cheapest per request; release depends on the payer voucher; x402 suite re-pinned |
| C: lxpay folded into a payments grant module | One module fewer; depends on another workstream |

## Decision
Option A is decided: each paid request settles as one draw through the lxpay precompile at 0x101A, and the minimum gas price for the draw sender class is at most 0.067 gwei.

## Consequences
- 0x101A is reserved for lxpay in the precompile address plan.
- The minimum fee per gas for the draw sender class is set to at most 0.067 gwei (modules/evm/types/params.go:81).
- Focused test: one draw per request yields one receipt at USD 0.001.
- Parity targets: one receipt per request; the existing x402 suite unchanged.

## Affects
- Addresses: 0x101A lxpay
- Modules: layerxpay, evm params, x402 seller
