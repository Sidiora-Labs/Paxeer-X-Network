# D14: Sponsorship path and per-identity budget home

Status: decided

## Context
Sponsored agent writes need one path and a home for per-identity budgets. An on-chain budget would be enforced in the EVM fee ante (modules/evm/ante/fee.go:36), which is a hard fork. The gas station already journals and replaces sponsor-nonce submissions (interop/crates/layerx-gas-station/src/station.rs:391-393).

## Options considered
| Option | Consequence |
|---|---|
| A: every sponsored agent write is a 7702 executeSponsored batch through the gas station, one paymaster nonce, budgets in a gas-station ledger keyed by DID via 0x1004 | No fork; budgets held by the gas station, which refuses sponsorship when unavailable |
| B: EVM nonce with feegrant-style sponsorship and an on-chain per-identity budget in the ante | Auditable on chain; the ante change is a hard fork |
| C: both | Two nonce spaces per agent to track |

## Decision
Option A is decided: every sponsored agent write is a 7702 executeSponsored batch through the gas station on one paymaster nonce, with per-identity budgets in a gas-station ledger keyed by DID through 0x1004.

## Consequences
- The gas station keeps a DID-keyed budget ledger and refuses sponsorship when the ledger is unavailable, with a focused test (interop/crates/layerx-gas-station/src/station.rs:391-393).
- The agent SDK uses a single paymaster nonce path.
- No ante change and no fork (modules/evm/ante/fee.go:36).

## Affects
- Addresses: 0x1004 addr, BatchCallAndSponsor
- Modules: gas station, agent SDK
