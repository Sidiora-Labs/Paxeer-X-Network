# D6: Precompile error encoding

Status: decided

## Context
The shared precompile base returns Error(string) reasons through an opt-in path (precompiles/common/precompiles.go:53). Every new precompile maps kernel result codes, which are defined in one table (include/layerx/lxp_result.h:42), to a revert reason. The dynamic-gas base replaces any error with a reason-less revert (precompiles/common/precompiles.go:177-184).

## Options considered
| Option | Consequence |
|---|---|
| A: Error(string) with the prefix LXP_<code> | Codes preserved as strings; no framework change for the standard base |
| B: ABI custom errors through a change to precompiles/common | Typed errors; the change touches every precompile |

## Decision
Option A is decided: every new precompile reverts with Error(string) carrying the prefix LXP_<code>, from one shared mapping table of kernel result codes. The single framework change is the opt-in reason path in the dynamic-gas base decided in D23.

## Consequences
- One shared LXP_<code> mapping table from kernel result codes (include/layerx/lxp_result.h:42), with a focused test asserting the revert string per code.
- New precompiles are built with the reason path (precompiles/common/precompiles.go:53).
- The dynamic-gas base gains an opt-in reason path for 0x1004 and 0x1001 (precompiles/common/precompiles.go:177-184), per D23.

## Affects
- Addresses: 0x1001 bank, 0x1004 addr, 0x101A-0x101D, 0x0901-0x0908 and every kernel-backed precompile
- Modules: precompiles/common
