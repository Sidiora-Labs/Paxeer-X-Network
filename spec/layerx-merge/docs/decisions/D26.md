# D26: Signer of the agent-host web payer

Status: decided

## Context
The agent host pays for web requests through a payer grant. The KMS crate signs payment grants today (human/crates/layerx-human-kms/src/attestor.rs:594). The embedded-wallet attestors hold key shares (human/wallet/attestor/internal/config/config.go:29) and sign at threshold 3 (human/wallet/attestor/internal/tss/ecdsa/ecdsa.go:26).

## Options considered
| Option | Consequence |
|---|---|
| A: KMS attestors | Server-side agent key; no wallet dependency |
| B: embedded-wallet attestors | One attestor set for all custody; the payer depends on the wallet signing stack |

## Decision
Option B is decided: the embedded-wallet attestor set signs the agent-host web payer grant, so one attestor set covers all custody.

## Consequences
- The KMS payment-grant path is retired for the agent-host web payer (human/crates/layerx-human-kms/src/attestor.rs:594).
- The attestor set signs the grant at its threshold (human/wallet/attestor/internal/tss/ecdsa/ecdsa.go:26).
- The chain verifies the combined attestor signature.

## Affects
- Addresses: 0x1019 xweb, 0x101A lxpay
- Modules: agent host, embedded-wallet attestors, KMS crate
