# D9: Program fee versus gas

Status: decided

## Context
Programs charge a fee of metering times prices from an active fee schedule (src/modules/programs/fees.c:20), paid to a fee treasury (include/layerx/programs.h:37). Gas on Paxeer X Network is near zero by policy.

## Options considered
| Option | Consequence |
|---|---|
| A: keep the program fee on top of near-zero gas | Program fee outcomes in the goldens unchanged |
| B: fold metering into gas | Every fee outcome in the goldens changes |

## Decision
Option A is decided: the program fee (metering times prices) is kept on top of near-zero gas.

## Consequences
- The program call fee path runs on the existing fee schedule (src/modules/programs/fees.c:20).
- Parity target: program fee outcomes in the existing goldens, unchanged.

- Addresses: 0x101D layerxprograms
- Modules: layerxprograms
