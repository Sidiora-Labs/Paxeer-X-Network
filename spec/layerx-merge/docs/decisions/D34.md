# D34: Tee attestor signer threshold and key type at 0x0907

Status: decided

## Context
The embedded-wallet attestor set requires exactly five endpoints and threshold three (human/wallet/gateway/src/attestor/client.ts:533), signing with secp256k1 at threshold 3 (human/wallet/attestor/internal/tss/ecdsa/ecdsa.go:26). The earlier implementation verified a single envelope signature with P-256, P-384 or Ed25519 keys.

## Options considered
| Option | Consequence |
|---|---|
| A: threshold signatures, 3 of 5, secp256k1 attestor keys | Matches the deployed attestor keys and the custody threshold |
| B: one attestor signature with P-256, P-384 or Ed25519 envelope keys | A second key type beside the attestor set |

## Decision
Option A is decided: 0x0907 accepts a quote envelope signed at the 3-of-5 threshold by the secp256k1 attestor keys.

## Consequences
- Envelope verification checks the combined 3-of-5 secp256k1 signature (human/wallet/attestor/internal/tss/ecdsa/ecdsa.go:26).
- The threshold matches the custody threshold of the attestor set (human/wallet/gateway/src/attestor/client.ts:533).

## Affects
- Addresses: 0x0907 teeAttestor
- Modules: layerxagent precompiles, embedded-wallet attestors
