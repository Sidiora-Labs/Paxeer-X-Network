# D23: Reason text for addr 0x1004 and bank 0x1001

Status: decided

## Context
addr 0x1004 (precompiles/addr/addr.go:38-43) and bank 0x1001 (precompiles/bank/bank.go:22-24) are dynamic-gas precompiles. The dynamic-gas base replaces any error with a reason-less revert (precompiles/common/precompiles.go:177-184), while the standard base has an opt-in reason path (precompiles/common/precompiles.go:53).

## Options considered
| Option | Consequence |
|---|---|
| A: an opt-in reason path in the dynamic-gas base, as the standard base has | Uniform LXP_ reason text; one narrow change to precompiles/common |
| B: leave both reverting without data | No framework change; clients receive no reason for DID and bank errors |

## Decision
Option A is decided: the dynamic-gas precompile base gains an opt-in reason path, so 0x1004 and 0x1001 revert with Error(string) carrying an LXP_ prefixed reason. This is the one framework change to precompiles/common under D6.

## Consequences
- The dynamic-gas error path returns the reason when opted in (precompiles/common/precompiles.go:177-184).
- addr and bank errors carry LXP_<code> text (precompiles/addr/addr.go:38-43, precompiles/bank/bank.go:22-24).
- Every other precompile keeps the standard reason path (precompiles/common/precompiles.go:53).

## Affects
- Addresses: 0x1001 bank, 0x1004 addr
- Modules: precompiles/common, evm binding keeper, bank
