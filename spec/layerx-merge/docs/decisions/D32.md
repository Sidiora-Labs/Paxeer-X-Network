# D32: Signer rule for submitPrice at 0x0903

Status: decided

## Context
The oracle function at 0x0903 (human/wallet/gateway/src/precompiles.ts:20) writes into the 0x1015 oracle store. The kernel admits an oracle observation only from a key in the market's permitted oracle key set (src/modules/perps/lx_oracle_intake.c:64), through the oracle push execute path (src/modules/perps/lx_perps_dispatch.c:914). D26 governs the web payer signer.

## Options considered
| Option | Consequence |
|---|---|
| A: the market's permittedOracleKeys via the caller's 0x1004-bound key, the same rule as the 0x1015 oracle push | One oracle rule across 0x0903 and 0x1015 |
| B: the embedded-wallet attestor set signs oracle prices | A second oracle signer rule |

## Decision
Option A is decided: submitPrice admits a price only when the caller's 0x1004-bound key is in the market's permittedOracleKeys, the same rule as the 0x1015 oracle push. D26 applies to the web payer only.

## Consequences
- submitPrice runs the kernel key-set check (src/modules/perps/lx_oracle_intake.c:64) and the oracle intake (src/modules/perps/lx_perps_dispatch.c:914).
- The 0x0903 and 0x1015 oracle paths share one signer rule.

## Affects
- Addresses: 0x0903 oracle, 0x1004 addr, 0x1015 layerxexchange
- Modules: layerxagent precompiles, layerxexchange
