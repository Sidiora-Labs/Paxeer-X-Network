# D29: One stream state for 0x0906 and 0x101B

Status: decided

## Context
The gateway routes agent streams to 0x0906 (human/wallet/gateway/src/precompiles.ts:23) with its own ABI (human/wallet/gateway/src/precompiles.ts:99). The kernel defines one stream activity set: open, top-up, meter, settle, pause, resume and close (include/layerx/lx_stream.h:26-32), which layerxpay at 0x101B executes.

## Options considered
| Option | Consequence |
|---|---|
| A: one surface; 0x0906 executes through the 0x101B stream keeper | One stream state and one set of semantics |
| B: two independent stores | Two states to keep consistent |

## Decision
Option A is decided: 0x0906 executes through the 0x101B stream keeper, so Paxeer X Network has one stream state and one set of stream semantics.

## Consequences
- 0x0906 methods map onto the kernel stream activities (include/layerx/lx_stream.h:26-32).
- The 0x0906 ABI is served from the 0x101B keeper (human/wallet/gateway/src/precompiles.ts:99).

## Affects
- Addresses: 0x0906 streams, 0x101B layerxpay
- Modules: layerxpay, layerxagent precompiles
