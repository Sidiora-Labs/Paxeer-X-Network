# D33: On-chain home of the tee attestor roots at 0x0907

Status: decided

## Context
The tee attestor at 0x0907 (human/wallet/gateway/src/precompiles.ts:24) verifies quotes against a per-family root list. Under D26 the root list is the embedded-wallet attestor set. xweb already registers an attestor set on chain (modules/xweb/keeper/keeper.go:90, modules/xweb/keeper/msg_server.go:71).

## Options considered
| Option | Consequence |
|---|---|
| A: reuse the xweb attestor set as the registered roots | One attestor set on chain |
| B: a new governance-set registry in 0x0907 params | A second registry to keep in step |

## Decision
Option A is decided: 0x0907 reads its roots from the xweb attestor set.

## Consequences
- 0x0907 resolves roots through the xweb attestor set (modules/xweb/keeper/keeper.go:90).
- Attestor registration stays in xweb (modules/xweb/keeper/msg_server.go:71).

## Affects
- Addresses: 0x0907 teeAttestor, 0x1019 xweb
- Modules: layerxagent precompiles, xweb
