# D13: Reference guest deployment

Status: decided

## Context
The interpreter, compute market and AI market reference guests are deployed on Paxeer X Network. Programs deploy through the kernel deploy execute path (src/modules/programs/deploy.c:485).

## Options considered
| Option | Consequence |
|---|---|
| A: deploy at the activation height through MsgDeploy | Same deploy path and goldens as any program |
| B: embed the artifacts in genesis or the upgrade handler | No post-upgrade step; artifacts become part of the upgrade binary |

## Decision
Option A is decided: the three reference guests are deployed at the activation height through MsgDeploy, with expected code hashes recorded in the activation runbook.

## Consequences
- The activation runbook carries one MsgDeploy step per reference guest with its expected code hash.
- Deployment runs the same path as any program (src/modules/programs/deploy.c:485).
- Parity target: deploy goldens, as for any program.

## Affects
- Addresses: 0x101D layerxprograms
- Modules: layerxprograms, activation runbook
