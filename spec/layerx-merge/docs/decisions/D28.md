# D28: Web precompile error naming

Status: decided

## Context
xweb registers its own Go errors (modules/xweb/types/errors.go:6-29). Origin-2 requests come from kernel programs (include/layerx/lx_web.h:23), whose errors are kernel result codes. Launchpad and exchange errors follow the LXP_<MODULE>_<NAME> rule.

## Options considered
| Option | Consequence |
|---|---|
| A: LXP_XWEB_* for Go-origin errors; kernel codes for kernel-origin (origin 2) errors | Consistent with the LXP_<MODULE>_<NAME> rule used for launchpad and exchange |
| B: map every xweb error to a kernel code | One code family; Go-origin errors lose their module names |

## Decision
Option A is decided: Go-origin xweb errors revert as LXP_XWEB_<NAME>, and kernel-origin (origin 2) errors keep their kernel codes.

## Consequences
- Each xweb Go error maps to one LXP_XWEB_ name (modules/xweb/types/errors.go:6-29).
- Origin-2 errors carry kernel codes (include/layerx/lx_web.h:23).

## Affects
- Addresses: 0x1019 xweb
- Modules: xweb, shared error registry
