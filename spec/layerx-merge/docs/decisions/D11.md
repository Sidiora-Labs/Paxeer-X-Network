# D11: Program-origin web request terms

Status: decided

## Context
Web requests carry an origin: origin 1 through the xweb precompile and origin 2 from a kernel program (modules/xweb/types/attestation.go:20, include/layerx/lx_web.h:23). Origin 2 is the kernel program half of paid search, and its fee terms differ from origin 1.

## Options considered
| Option | Consequence |
|---|---|
| A: per-asset fee as the kernel charges it, with xweb params extended, and any-amount payment without refund | Paid amounts and outcomes match the kernel goldens; overpayments are not refunded |
| B: single-denom fee with the origin-1 exact fee and a timeout refund | Paid amounts per asset change; refunds on timeout |

## Decision
Option A is decided: origin 2 keeps the kernel per-asset fee with no-refund parity, carried in an origin-2 per-asset fee table in xweb params.

## Consequences
- xweb params gain the origin-2 per-asset fee table (modules/xweb/types/attestation.go:20).
- The program request path keeps kernel terms (include/layerx/lx_web.h:23).
- Parity target: kernel goldens for paid amounts and outcomes.

## Affects
- Addresses: 0x1019 xweb, 0x101D layerxprograms
- Modules: xweb, layerxprograms
