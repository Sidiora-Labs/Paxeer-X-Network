# D30: Gas rule across the new precompiles

Status: decided

## Context
Existing precompiles charge a flat KV cost plus a per-byte cost (precompiles/common/precompiles.go:286-292), and the exchange precompile computes gas from inputs, signatures, proof nodes and writes (precompiles/layerxexchange/layerxexchange.go:182). Kernel gas units are payload-length based and feed the program fee (D9).

## Options considered
| Option | Consequence |
|---|---|
| A: a fixed per-method gas table, in the DefaultGasCost pattern; kernel gas units not converted | Predictable gas with no kernel coupling |
| B: convert kernel gas units to EVM gas by a factor | Gas follows payload length; couples EVM gas to kernel metering |

## Decision
Option A is decided: every new precompile charges from a fixed per-method gas table; kernel gas units stay internal to the program fee.

## Consequences
- Each new precompile carries a per-method gas table, following the existing pattern (precompiles/common/precompiles.go:286-292).
- Gas numbers per method are set at activation rehearsal from a benchmark.
- Kernel gas units are not converted to EVM gas (precompiles/layerxexchange/layerxexchange.go:182 remains the exchange formula).

## Affects
- Addresses: 0x101A-0x101D, 0x0901-0x0908
- Modules: every new precompile
