# D12: Origin-2 observation admission

Status: decided

## Context
The kernel caps web attestors at 16 (include/layerx/lx_web.h:29) and carries its own network id; xweb caps attestors at 64 (modules/xweb/types/keys.go:21) and signs over the EVM chain id (modules/xweb/keeper/fulfil.go:72). Both intakes verify 65-byte secp256k1 signatures (include/layerx/lx_web.h:30, src/modules/web/lx_web_intake.c:227), so the key type is common.

## Options considered
| Option | Consequence |
|---|---|
| A: cap origin 2 at 16 signers; keep the kernel network id as an xweb param | Preimage vectors and attestor tooling unchanged; kernel admission parity |
| B: accept 64 signers and switch to the chain id | Changes which observations admit; new vectors; one id for both origins |

## Decision
Option A is decided: origin-2 observations admit at most 16 signers and sign over the kernel network id, held as an xweb param.

## Consequences
- The kernel network id becomes an xweb param, and the fulfil preimage branches by origin (modules/xweb/keeper/fulfil.go:72).
- Origin 2 keeps the 16-signer cap (include/layerx/lx_web.h:29); origin 1 keeps 64 (modules/xweb/types/keys.go:21).
- Parity targets: existing preimage vectors and kernel admission outcomes, unchanged.

## Affects
- Addresses: 0x1019 xweb
- Modules: xweb, kernel web module
