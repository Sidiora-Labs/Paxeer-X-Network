# D27: Typed exact payment at 0x101A

Status: decided

## Context
x402 sellers need a payment that carries a reference. A kernel send carries from, to, asset, amount, expiry and an idempotency key (include/layerx/lxp_ledger.h:138), and the send idempotency key equals the activity idempotency key (src/modules/asset/lx_asset_registry.c:149-150).

## Options considered
| Option | Consequence |
|---|---|
| A: a typed payExact as a send with a payment reference, logging PaymentExact | x402 suite unchanged; a payment carries its reference |
| B: drop payExact and PaymentExact; exact payments use send(bytes) | One method fewer; no typed reference |

## Decision
Option A is decided: 0x101A carries payExact, a typed send whose payment reference is the send idempotency key, and each applied payExact logs PaymentExact.

## Consequences
- payExact maps onto the kernel send fields (include/layerx/lxp_ledger.h:138).
- The payment reference is the send idempotency key (src/modules/asset/lx_asset_registry.c:149-150).
- The PaymentExact log is emitted beside the Transfer log.

## Affects
- Addresses: 0x101A lxpay
- Modules: layerxledger, layerxpay, x402 seller
