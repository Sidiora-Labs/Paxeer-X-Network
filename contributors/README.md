# Contributors

Paxeer X Network recognises contributors to this repository: patches, review, documentation, tests and operations all count. Names are listed in [CONTRIBUTORS.md](../CONTRIBUTORS.md).

Recognition is not the same as maintainer status. Governance is described in [GOVERNANCE.md](../GOVERNANCE.md).

## How names are added

1. Contribute under Apache 2.0 with Developer Certificate of Origin sign-off (`git commit -s`). See [CONTRIBUTING.md](../CONTRIBUTING.md).
2. After the change lands on `main`, the commit author is a contributor. [CONTRIBUTORS.md](../CONTRIBUTORS.md) lists people from `git shortlog -sn --no-merges origin/main`, excluding bots.

Do not open a public issue to claim credit for a security report. Follow [SECURITY.md](../SECURITY.md).
