# JVM SDK

Java and Kotlin SDK (`com.sidiora.layerx:layerx-sdk`, package
`com.sidiora.layerx.sdk`) for the agent and human APIs of the LayerX kernel
domain of Paxeer X Network. Hosted documentation lives at
[docs.paxeer.app](https://docs.paxeer.app/).

## Features

- **Schema-generated types**: `GeneratedSchema` holds the agent and human
  operation constants, request and response records, and events, generated by
  [`../generators/generate_jvm.py`](../generators/generate_jvm.py).
- **Local verification**: `verify.LocalVerifier` verifies receipts, batch
  inclusion, Merkle proofs and checkpoints with built-in signature verification.
- **Resumable streaming**: `ResumableStream` publishes a `Flow.Publisher` over
  cursor-paged sources.
- **Integer-only money**: `ProtocolAmount` is backed by `BigInteger` and has no
  floating-point constructor.
- **Security primitives**: `IdempotencyKey` and `SecretBytes`.
- **Kotlin helpers**: top-level functions and `ProductionClient` extensions in
  `LayerX.kt` (`protocolAmount`, `idempotencyKey`, `streamCursor`, typed
  `agent`/`human` calls with default options).

## Requirements

- Java 21 (`maven.compiler.release` in [`pom.xml`](pom.xml))
- Maven; the build depends on Jackson, Bouncy Castle and the Kotlin 2.0.20
  standard library

## Build

```bash
mvn -f platform/sdk/jvm/pom.xml install
```

[`platform/release/registries.kvx`](../../release/registries.kvx) registers the
`com.sidiora.layerx:layerx-sdk` coordinate for Maven Central. Once installed
locally, depend on it as:

```xml
<dependency>
  <groupId>com.sidiora.layerx</groupId>
  <artifactId>layerx-sdk</artifactId>
  <version>0.1.0</version>
</dependency>
```

## Quick start

The limited beta has not opened yet. The gateway API becomes available when it
does. `humanBaseUri` is the human API base URI and `agentEndpoint` the agent
JSON-RPC endpoint you are issued with beta access.

### Java

```java
import com.sidiora.layerx.sdk.*;
import java.net.URI;

var credential = new HttpProductionTransport.BearerCredential(
    new SecretBytes("your-api-key".getBytes()));
var transport = HttpProductionTransport.create(
    URI.create(humanBaseUri), URI.create(agentEndpoint), credential);
var client = new ProductionClient(transport);

var money = new GeneratedSchema.HumanModels.Money(ProtocolAmount.parse("1000000"), currency);
var request = new GeneratedSchema.HumanOperations.MoveQuoteRequest("source", "destination", money);
var response = client.human(GeneratedSchema.HumanOperations.MOVE_QUOTE, request,
    ProductionClient.Options.none());
```

### Kotlin

```kotlin
import com.sidiora.layerx.sdk.*
import java.net.URI

val credential = HttpProductionTransport.BearerCredential(
    SecretBytes("your-api-key".toByteArray()))
val transport = HttpProductionTransport.create(
    URI.create(humanBaseUri), URI.create(agentEndpoint), credential)
val client = ProductionClient(transport)

val money = GeneratedSchema.HumanModels.Money(protocolAmount("1000000"), currency)
val request = GeneratedSchema.HumanOperations.MoveQuoteRequest("source", "destination", money)
val response = client.human(GeneratedSchema.HumanOperations.MOVE_QUOTE, request)
```

String-named and `Class`/`TypeReference` overloads of `agent` and `human` remain
available. The typed `GeneratedSchema` operation constants keep agent and human
operations, requests, responses and events distinct at the JVM type boundary.
Runnable examples are in [`examples/`](examples).

## Local verification

```java
import com.sidiora.layerx.sdk.verify.LocalVerifier;

var authorized = new LocalVerifier.AuthorizedReceiptBatch(
    batchId, asset, previousStateRoot, resultingStateRoot, sequencerPublicKey);
var verified = LocalVerifier.verifyReceipt(canonicalReceipt, authorized);
System.out.println("Receipt verified: " + verified.level());
```

`level()` is a `LocalVerifier.VerificationLevel`: `SEQUENCER_SIGNED`,
`BATCH_INCLUDED`, `STATE_PROVEN`, `CHECKPOINT_FINALISED` or
`SETTLEMENT_ANCHORED`.

## Streaming

```java
import com.sidiora.layerx.sdk.ResumableStream;
import java.util.concurrent.Flow;

var stream = new ResumableStream<Event>(new ResumableStream.Cursor("initial"));
Flow.Publisher<ResumableStream.Event<Event>> publisher =
    stream.publisher(cursor -> fetchPage(cursor));
```

`fetchPage` returns a `CompletionStage<ResumableStream.Page<Event>>` carrying the
requested cursor, the page's events and the next cursor.

## Money

```java
import com.sidiora.layerx.sdk.ProtocolAmount;
import java.math.BigInteger;

ProtocolAmount amount = ProtocolAmount.of(new BigInteger("1000000"));
ProtocolAmount parsed = ProtocolAmount.parse("1000000");
```

## Errors

```java
try {
    var result = client.agent("operation", request, ResponseType.class, options)
        .toCompletableFuture().join();
} catch (java.util.concurrent.CompletionException failure) {
    if (failure.getCause() instanceof PlatformSdkException e) {
        System.err.println("Code: " + e.code().wire());
        System.err.println("Retry: " + e.retry().wire());
        if (e.retryAfterMs() != null) {
            System.err.println("Retry after: " + e.retryAfterMs() + "ms");
        }
    }
}
```
