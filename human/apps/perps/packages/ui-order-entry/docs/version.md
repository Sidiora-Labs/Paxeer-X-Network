# version.ts

## Overview

Registers the package version on `window.__PAXEER_NETWORK_VERSION__["@paxeer-network/ui-order-entry"]` for runtime version reporting. Exports the version string as default.

## Exports

- **Default:** `"2.9.1"` (string)

## Usage

```ts
import version from "@paxeer-network/ui-order-entry/version";
// or read from window.__PAXEER_NETWORK_VERSION__
```
