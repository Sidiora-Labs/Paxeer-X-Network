# constants (vault-card)

## Overview

Shared constants and helper for vault card: paxeer-network icon URL, default title/description, and broker icon URL by brokerId.

## Exports

| Name | Type | Description |
|------|------|-------------|
| PAXEER_NETWORK_ICON | string | paxeer-network logo URL |
| PAXEER_NETWORK_VAULT_TITLE | string | "paxeer-network OmniVault" |
| PAXEER_NETWORK_VAULT_DESCRIPTION | string | Default vault description text |
| getBrokerIconUrl | (brokerId: string) => string | Returns icon URL for paxeer-network, woofi_pro, aden, vooi, or generic broker logo |
