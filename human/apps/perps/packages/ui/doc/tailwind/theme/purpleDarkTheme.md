# purpleDarkTheme.ts

## purpleDarkTheme.ts 的职责

Purple dark theme CSS variables (`PURPLE_DARK_THEME_CSS_VARS`): the previous default dark look retained as an optional preset (Manrope, richer shade steps, visible gradients).

## purpleDarkTheme Example

```ts
import { PURPLE_DARK_THEME_CSS_VARS } from "@paxeer-network/ui";
```
