# Independent integration assurance primitives

Run `python3 -m unittest discover -s tools/launchpad/production/integration -p 'test_*.py' -v` from the repository root. Standard-library Python only; no product reducer imports. Arithmetic inputs and hashes in tests are explicitly synthetic and never chain receipt evidence. HTTP adapter tests use a real bounded loopback server; process cleanup uses an actual directly owned process group. Docker negative boundary tests do not fault any running container.

`inventory` requires complete contiguous block observations including empty blocks, anchored to an independently supplied start height and parent hash. It checks chain125 event/header identity, global log ordering, complete-block agreement, and transport duplicate equality. The caller must obtain and authenticate raw RPC receipts, deployed ABI/code provenance and complete log ranges independently. These normalized models cannot authenticate their own input or establish a deployment's activation epoch. Disagreement raises quarantine; no ordinary committed-block rollback exists.

`Ledger` uses remaining weighted cost, integer floor partial allocation, and consumes the full residual cost upon complete disposal. Quantity and prices are raw token and raw USDL units. Buy inputs MUST be actual net tokens received and total actual USDL debited; sell inputs MUST be actual inventory removed and net USDL credited. Pool execution volume is a distinct fact and MUST NOT be conflated with wallet fee-inclusive ledger debit/credit. Buy token recipient owns newly received inventory. Sell inventory_owner must be explicit and is independent of the USDL proceeds recipient. Sell realized proceeds are attributed to the disposed inventory position as economic execution proceeds even when delivered to another beneficiary; actual wallet cashflow is a separate ledger. No inference from transaction sender is allowed. Unknown incoming transfer basis remains unknown and blocks disposal attribution until authoritative lot selection is supplied. `unrealized` takes an exact Fraction of raw USDL per raw token; human price must be multiplied by 10^6/10^tokenDecimals externally. This is an assurance model, not a replacement PnL service.

`candles` takes independently normalized execution amounts, sorts canonical height/transaction/global-log positions, uses exact Fraction human USDL/token ratios and UTC seven intervals (weekly Monday). Empty buckets are omitted. It does not assert database transaction commit, revisions, outbox publication or runtime coverage. Those require actual integrated service outputs and durable transaction fault tests. Invoke inventory before either oracle; events alone have no completeness proof.

`LocalHTTP` calls actual frozen routes on explicit numeric loopback allocated ports, bounds body/response, does not follow redirects or resolve hostnames. Caller supplies the exact approved port inventory. `OwnedProcess` owns only the child it starts and its process group, terminates then kills that group if needed. It must never wrap untrusted executable arguments. It does not reserve ports: a service must fail startup on occupied ports and caller must verify child liveness before fixture mutation.

`DockerFaults` requires exact 64-character container IDs and namespace/attempt/role/isolated labels established by the coordinator. Host networking/PID namespaces, privileged containers and every mounted container are denied. No shell, exec, delete, prune, shared Compose project or peer faults are exposed. Persistent database/broker fault tests therefore need a separate reviewed named-volume ownership extension; this initial adapter intentionally cannot fault existing shared bootstrap resources. Action allowlists are scoped per exact target. No containers were started or disrupted in phase1.

Every scenario in scenario-inventory.json remains blocked for production qualification. Required next inputs: integrated Go services and browser, real isolated Sidiora receipts bound to current ABI registry, transactional PG/outbox/inbox writers, dedicated NATS R3 and PG failover inventory, cross-region restore target, object/scanner sandbox, actual elapsed 72-hour replay, mutation copies of product code and coverage profiles. 500K DAU, 10K events/sec, AZ/region recovery and full journeys remain unproven. No core oracle, graduation, ordinary reorg or embedded wallet assumptions are introduced.
